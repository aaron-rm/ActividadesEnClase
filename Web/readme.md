# 🌐 Actividades de desarrollo web

Prácticas de HTML y CSS y aplicaciones JSP con acceso a MySQL, organizadas bajo [Programación de Software 2](Programaci%C3%B3n%20de%20Software%202/readme.md).

Los proyectos conservan sus imágenes, audio, video y configuración de Eclipse dentro de la misma entrega. Las páginas estáticas se abren en un navegador; los proyectos JSP requieren un servidor Tomcat y las bases de datos indicadas en sus README.
