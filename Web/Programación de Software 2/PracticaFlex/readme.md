# Práctica de Flexbox

Página de comida rápida para practicar disposición de elementos con CSS: barra de navegación, portada, tarjetas de hamburguesas, pizzas y hot dogs, y pie de página.

| Archivo | Función |
| --- | --- |
| [index.html](index.html) | Estructura y contenido de la página. |
| [style.css](style.css) | Estilos y distribución de elementos. |

## Visualización

Abre `index.html` en un navegador y conserva `style.css` en la misma carpeta. Los enlaces con `#` y el botón de pedido forman parte de la maqueta; no implementan un sistema de pedidos.
