# Práctica 2: recetas y formulario 🍽️

Sitio estático de recetas para practicar navegación entre páginas, imágenes, tablas y controles de formulario.

| Página | Contenido |
| --- | --- |
| [HOME.html](HOME.html) | Portada y enlaces a las recetas y al registro. |
| [DESAYUNO.html](DESAYUNO.html) | Receta de desayuno. |
| [ALMUERZO.html](ALMUERZO.html) | Receta de almuerzo. |
| [CENA.html](CENA.html) | Receta de cena. |
| [FORMULARIO.html](FORMULARIO.html) | Datos personales, facultad, intereses y otros controles HTML. |

## Visualización

Abre `HOME.html` en un navegador y conserva la carpeta `img`, que contiene las portadas. El formulario es una práctica de interfaz: no tiene un procesador de registro ni una base de datos asociada.
