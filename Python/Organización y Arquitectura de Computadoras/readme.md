# Organización y Arquitectura de Computadoras

Proyectos procedentes de `OAC` de TrabajosEnClase. Incluyen procesamiento de instrucciones y un juego de escritorio con comunicación entre computadoras.

| Trabajo | Contenido |
| --- | --- |
| [Proyecto 4](Proyecto%204/readme.md) | Scripts Python para depurar un archivo ASM, resolver etiquetas y generar una ROM hexadecimal. |
| [Tictactoe3d.py](Tictactoe3d.py) | Versión del juego Tic-Tac-Toe 3D contenida en un solo archivo. |
| [Semestral](Semestral/README.md) | Versión modular del juego, con bot, modo local, red y chat; incluye documentación en Word. |

El Proyecto 4 mantiene juntos Python, ASM y ROM porque los scripts leen y generan esos archivos. Las dos versiones del juego se conservan como entregas independientes.

## Versión en un archivo

Desde esta carpeta, con Python 3 y Tkinter disponible:

```powershell
python -m pip install matplotlib
python Tictactoe3d.py
```

Para el proyecto modular, consulta el README de `Semestral` y ejecuta su `main.py`.
