# Biblioteca y análisis de algoritmos 📚

[ProyectoFinal.py](ProyectoFinal.py) implementa un catálogo de libros con interfaz Tkinter. Permite buscar, filtrar por autor, ordenar los resultados y consultar el detalle de un libro.

## Algoritmos

- Búsqueda binaria por ISBN y búsqueda lineal por texto.
- Ordenamiento del catálogo por atributos.
- Comparación empírica de intercambio directo, selección directa e inserción directa.
- Medición de tiempo con `time` y de memoria con `tracemalloc`.

## Ejecución

Desde esta carpeta, con Python 3 y Tkinter disponible:

```powershell
python -m pip install plotly
python ProyectoFinal.py
```

Plotly se utiliza para las gráficas del análisis. El código contempla su ausencia, aunque en ese caso no dispone de esas gráficas. Los libros de ejemplo están definidos en el propio archivo; no se requiere una base de datos externa.

El [PDF del proyecto](PROYECTO%20FINAL.pdf) contiene el enunciado y las rúbricas académicas.
