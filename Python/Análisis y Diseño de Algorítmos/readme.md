# Análisis y Diseño de Algoritmos en Python

Dos aplicaciones que combinan resolución de problemas, validación de entradas y mediciones empíricas de tiempo y memoria.

| Entrega | Aplicación | Dependencias |
| --- | --- | --- |
| [Parcial 2](Parcial%202/Parcial2.py) | Sistema de rutas de entrega: matriz de distancias, distribución de paquetes, asignación de rutas, métricas y gráficas. | Matplotlib. |
| [Proyecto final](Proyecto%20Final/readme.md) | Biblioteca gráfica con búsquedas, filtros, ordenamientos y comparación de algoritmos. | Tkinter; Plotly para las gráficas. |

## Parcial 2

Desde `Parcial 2`:

```powershell
python -m pip install matplotlib
python Parcial2.py
```

El menú permite introducir o generar una matriz de distancias, editarla, consultar rutas y ejecutar el análisis empírico. Las rutas usan una selección del punto más cercano disponible; las métricas incluyen distancias y tiempos estimados.

El [enunciado del proyecto final](Proyecto%20Final/PROYECTO%20FINAL.pdf) conserva objetivos, instrucciones y rúbricas de búsqueda, ordenamiento y análisis de complejidad.
