## Dependencias

Utiliza Python 3 y consulta el README de cada entrega para instalar solo sus dependencias:

- **NumPy:** sistemas lineales de Métodos Numéricos.
- **Matplotlib:** rutas de reparto y Tic-Tac-Toe 3D.
- **Plotly:** gráficas del análisis empírico de la biblioteca.
- **Tkinter:** biblioteca e interfaces de Tic-Tac-Toe 3D.

Ejecuta cada programa desde su carpeta para mantener las importaciones locales. Los archivos `__pycache__` y `.pyc` son cachés regenerables y se ignoran en Git.
