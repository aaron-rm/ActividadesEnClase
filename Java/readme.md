## Compilación

Compila cada entrega por separado: distintas carpetas reutilizan nombres de clases. Usa `javac -encoding UTF-8` para fuentes con tildes. Cuando exista una declaración `package`, genera las clases con `javac -d` y ejecuta el nombre completo del paquete.

Los archivos `.form` utilizan el formato del diseñador de interfaces de IntelliJ IDEA. Esas actividades requieren procesar sus formularios y configurar sus recursos en el IDE; una compilación directa del `.java` puede no inicializar los componentes de la interfaz.
