# Portafolio Académico: Análisis, Diseño y Estructura de Datos 🚀

Este repositorio centraliza los proyectos y laboratorios desarrollados durante el primer semestre de 2025 en la **Universidad Tecnológica de Panamá**. El contenido abarca desde los fundamentos de la programación en C/C++ hasta el modelado avanzado de objetos.

## 📂 Organización del Repositorio

El portafolio se divide en tres áreas principales de estudio:

### 1. Estructura y Representación de Datos
Proyectos enfocados en la organización técnica de la información y gestión de memoria.
* **[Administrador de Biblioteca](./Proyecto_Biblioteca):** Sistema de gestión para el catálogo de libros universitarios. Implementa registros (`structs`), arreglos y validaciones de datos (ISBN, años, categorías).

### 2. Análisis y Diseño de Algoritmos (Laboratorios)
Serie de prácticas orientadas al dominio de la lógica de programación y flujos de control.
* **[Laboratorio 4: Estructuras de Decisión](./Lab4_Decisiones):** Uso de condicionales simples, anidados y selección múltiple (`if`, `else`, `switch`) para resolver problemas de lógica.
* **[Laboratorio 5: Procesos Repetitivos](./Lab5_Ciclos):** Implementación comparativa de bucles (`for`, `while`, `do...while`) y gestión de nómina mediante arreglos de registros.

### 3. Modelado de Sistemas (Objetos Abstractos)
Ejercicios de diseño conceptual y arquitectura de software orientada a objetos.
* **[Actividad 4: Modelado de Objetos](./Actividad4_Objetos):** Diseño de sistemas administrativos (Facturación, Matrícula, Sesiones) enfocándose en las relaciones entre clases como composición y dependencia.

## 🛠️ Tecnologías y Herramientas
* **Lenguajes:** Java
* **Conceptos Clave:** Estructuras de Control, Tipos de Datos Abstractos (TDA), Relaciones de Objetos, Gestión de Planillas.
* **Entorno:** Compiladores estándar de C/C++ y herramientas de análisis de algoritmos.
