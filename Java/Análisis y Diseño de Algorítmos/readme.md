# Análisis y Diseño de Algoritmos en Java

Ejercicios de consola para practicar selección, repetición y almacenamiento de datos.

| Entrega | Contenido |
| --- | --- |
| [Laboratorio 4](Laboratorio4/) | Porcentaje de avance, validación de contraseña, clasificación de notas y menú de tareas. |
| [Laboratorio 5](Laboratorio5/) | Lectura de números con `for`, `while` y `do-while`; suma y promedio; registro de empleados y salarios. |

## Ejecución

Cada programa es independiente. Ejemplo desde `Laboratorio4`:

```powershell
javac -encoding UTF-8 Problema1.java
java Problema1
```

En `Laboratorio5`, `ArreglosYRegistrosRepetición.java` incluye la clase auxiliar `Empleado` y calcula salarios a partir de horas y pago por hora.
