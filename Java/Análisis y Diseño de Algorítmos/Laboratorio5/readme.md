# Laboratorio N.5: Procesos Repetitivos y Colección de Datos 🔄

Este repositorio contiene el desarrollo del quinto laboratorio de la asignatura **Análisis y Diseño de Algoritmos**, bajo la supervisión del profesor **César O. González C.** en la Facultad de Ingeniería de Sistemas Computacionales.

## 🎯 Objetivo
El propósito de esta actividad es dominar el uso de estructuras iterativas y colecciones de datos para optimizar soluciones algorítmicas:
* Aplicar los principales ciclos repetitivos (`for`, `while`, `do...while`) en programas sencillos.
* Transformar narraciones lógicas en soluciones funcionales que utilicen arreglos y registros.

## 🛠️ Contenido del Laboratorio

### Parte I: Comparación de Ciclos
Se desarrolla un sistema para registrar 5 números enteros, almacenarlos en un arreglo y calcular su suma y promedio. El ejercicio requiere implementar la misma solución tres veces utilizando:
1. **Versión 1:** Estructura `for`.
2. **Versión 2:** Estructura `while`.
3. **Versión 3:** Estructura `do...while`.

### Parte II: Arreglos y Registros (Structs)
Implementación de un sistema de gestión de nómina para una empresa que registra hasta 10 empleados.
* **Estructura del Registro (`Empleado`):** Incluye los campos nombre (cadena), horas (entero) y pago por hora (flotante).
* **Funcionalidad:**
    * Lectura de datos para $n$ empleados ($n \le 10$).
    * Cálculo del salario individual (horas × pago).
    * Cálculo del salario total de la planilla.

## 📋 Requisitos de Entrega
El informe final se presenta en formato PDF e incluye:
* **Hoja de Presentación:** Siguiendo el formato institucional dado en clase.
* **Desarrollo:** Código fuente en C, Python o Java junto con capturas de pantalla de la ejecución que validen el funcionamiento.
* **Análisis:** Respuestas justificadas a las preguntas sobre eficiencia de ciclos y ventajas del uso de `structs`.
* **Consideraciones Finales:** Reflexión personal sobre el aprendizaje y dificultades encontradas.
