# Laboratorio N.4: Estructuras de Decisión 💻

Este repositorio contiene el desarrollo del cuarto laboratorio de la asignatura **Análisis y Diseño de Algoritmos**, impartida por el profesor **César O. González C.** en la Facultad de Ingeniería de Sistemas Computacionales de la Universidad Tecnológica de Panamá.

## 🎯 Objetivo
El propósito de esta actividad es dominar el uso de estructuras condicionales para la resolución de problemas lógicos:
* Comprender el uso de estructuras condicionales en algoritmos.
* Aplicar las sentencias `if`, `if...else`, `if...else` anidado y `switch case`.
* Transformar narraciones lógicas en soluciones funcionales en lenguaje C, Python o Java.

## 🛠️ Contenido del Laboratorio

### Narración 1: Uso de `if` Simple
* **Escenario:** Control de avance de tareas (rango 0-100).
* **Lógica:** Si el avance es igual a 100, se muestra el mensaje "Tarea completada".

### Narración 2: Uso de `if...else`
* **Escenario:** Sistema de autenticación simple.
* **Lógica:** Validación de la contraseña "admin123". Si es correcta, muestra "Acceso concedido"; de lo contrario, "Acceso denegado".

### Narración 3: Uso de `if...else` Anidado
* **Escenario:** Asignación de calificaciones académicas basadas en una nota final (0-100).
* **Escala:**
    * 91-100: "A"
    * 81-90: "B"
    * 71-80: "C"
    * 61-70: "D"
    * 0-60: "F"

### Narración 4: Uso de `switch case`
* **Escenario:** Menú de gestión de tareas con cuatro opciones:
    1. Registrar tarea.
    2. Listar tareas.
    3. Eliminar tarea.
    4. Salir.

## 📋 Requisitos de Implementación
Para cada programa se incluye:
* **Código Fuente:** Implementación técnica de la lógica solicitada.
* **Preguntas de Análisis:** Justificación teórica sobre la selección de estructuras y validación de datos.
* **Capturas de Pantalla:** Evidencia del correcto funcionamiento y manejo de errores.

## ⚙️ Recursos
* **Computador** con editor de texto y compilador.
* **Plataforma TEAMS** para la entrega del informe final.
