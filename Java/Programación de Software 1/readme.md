## Ejecución

Compila cada entrega por separado. Ejemplo desde `Laboratorio 5`:

```powershell
javac -encoding UTF-8 *.java
java Main
```

Para las entregas con `package`, usa `javac -d out` y ejecuta la clase con su paquete. Los `.form` son formularios de IntelliJ IDEA: conserva su vinculación con las clases y utiliza el diseñador de interfaces para las actividades que dependen de ellos.
