# Estructura y Representación de Datos

[Proyecto1ERD.java](Proyecto1ERD.java) implementa un catálogo de biblioteca en consola. Trabaja con arreglos para almacenar la información de los libros y permite operar sobre los registros mediante un menú.

## Funciones

- Agregar libros.
- Buscar por título o autor.
- Listar el catálogo.
- Filtrar por año o categoría.
- Editar un libro existente.

## Ejecución

Desde esta carpeta, con un JDK:

```powershell
javac -encoding UTF-8 Proyecto1ERD.java
java Proyecto1ERD
```

Los registros se gestionan en memoria durante la ejecución.
