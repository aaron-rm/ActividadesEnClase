## Ejecución

Compila un archivo a la vez, desde su carpeta. Ejemplo para el Laboratorio 3 de algoritmos:

```powershell
g++ Laboratorio3.cpp -o Laboratorio3.exe
.\Laboratorio3.exe
```

Para un archivo `.c`, utiliza un compilador de C, por ejemplo `gcc`. Algunos ejercicios conservan funciones o comandos propios de su entorno original en Windows; revisa el archivo concreto antes de ejecutarlo en otro sistema. Los ejecutables históricos del semestral se mantienen junto a sus fuentes.
