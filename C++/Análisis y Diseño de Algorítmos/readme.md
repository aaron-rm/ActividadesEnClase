# Análisis y Diseño de Algoritmos en C/C++

El **Laboratorio 3** trabaja almacenamiento intermedio, procesamiento secuencial y robustez de una solución que calcula el total y el promedio de horas estimadas para tres tareas.

| Archivo | Función |
| --- | --- |
| [Laboratorio3.cpp](Laboratorio3.cpp) | Lectura de horas, validación de entradas numéricas no negativas y resumen. |
| [Lab3_ADA_25.pdf](Lab3_ADA_25.pdf) | Enunciado, preguntas de análisis, instrucciones de entrega y rúbrica. |

## Ejecución

Desde esta carpeta, con un compilador de C++:

```powershell
g++ Laboratorio3.cpp -o Laboratorio3.exe
.\Laboratorio3.exe
```

La implementación usa funciones de entrada y salida de C dentro de un archivo `.cpp`.
